# Публикация интеллектуального поиска

Серверная часть находится в каталоге `api/`. Сайт остаётся на GitHub Pages, API размещается отдельно на Render.

## 1. Создать API-ключ OpenAI

1. Откройте https://platform.openai.com/api-keys.
2. Войдите в аккаунт OpenAI Platform.
3. Создайте отдельный API-ключ для этого проекта.
4. Не отправляйте ключ в переписке, не добавляйте его в GitHub и не вставляйте в HTML/JavaScript.
5. В настройках биллинга OpenAI Platform проверьте способ оплаты и установите доступные лимиты расходов.

Подписка ChatGPT и использование OpenAI API — разные продукты и тарифицируются отдельно.

## 2. Развернуть API на Render

В корне репозитория есть файл `render.yaml`, поэтому можно использовать Blueprint:

1. Создайте аккаунт на https://render.com/.
2. Нажмите **New** → **Blueprint**.
3. Подключите GitHub и выберите репозиторий `89158142819/clinical-recommendations`.
4. Render прочитает `render.yaml` и покажет параметры создаваемого сервиса.
5. Для переменной `OPENAI_API_KEY` вставьте API-ключ OpenAI. Это секретная переменная Render — её значение не должно появляться в GitHub.
6. Подтвердите создание сервиса.

При сборке Render установит зависимости и выполнит `api/build_search_index.py`. Скрипт построит поисковый индекс из опубликованных JSON-документов в `site-data/docs/`.

Команда запуска: `uvicorn api.main:app --host 0.0.0.0 --port $PORT`.

## 3. Проверить сервер

После успешного Deploy откройте адрес сервиса Render и добавьте в конец:

`/health`

Сервер должен вернуть JSON со статусом `ok`, количеством проиндексированных документов и фрагментов.

## 4. Подключить адрес API к странице

1. Скопируйте публичный адрес сервиса Render, например `https://имя-сервиса.onrender.com`.
2. Откройте `assistant.html` в GitHub.
3. Найдите строку:

`const API_BASE_URL = "https://YOUR-RENDER-SERVICE.onrender.com";`

4. Замените только адрес внутри кавычек на фактический URL вашего сервиса.
5. Сохраните изменение. GitHub Pages автоматически обновит страницу.

## 5. Что важно знать

- Регистрация посетителям сайта не нужна: API открыт для запросов с сайта.
- Ключ OpenAI хранится только в секретах Render, браузер его не получает.
- В API предусмотрено ограничение частоты запросов с одного IP. Для публичной эксплуатации дополнительно настройте лимиты расходов в OpenAI Platform и при росте нагрузки подключите внешний rate limiter/WAF.
- В конфигурации Render выбран бесплатный тариф для первоначального тестирования. Бесплатный сервис может засыпать после периода бездействия, поэтому первый запрос после простоя может выполняться заметно дольше. Для постоянной рабочей эксплуатации следует оценить платный тариф.
- Не передавайте в форму ФИО, даты рождения, номера полисов, медицинские документы и другие персональные данные пациентов.
- Ответы являются справочной выжимкой из найденных фрагментов, а не заменой полной клинической рекомендации или клинического решения врача.

## 6. Техническая проверка

Workflow **«Проверка интеллектуального поиска»** запускается при изменении API-файлов или документов в `site-data/`. Он проверяет синтаксис Python и собирает поисковый индекс. Сам по себе успешный workflow не означает, что внешний сервис Render уже опубликован.
